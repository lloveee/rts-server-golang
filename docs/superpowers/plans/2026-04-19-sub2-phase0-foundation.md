> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Extend Go + C# sim structs, hash, Marshal/Unmarshal, and the golden export tool with the Sub-2 data model — without adding any gameplay logic — so that later vertical slices (economy, combat, construction, pathfinding, FOW, polish) can land one subsystem at a time.

Extend the canonical FNV-1a hash and Marshal/Unmarshal to cover every new field in a fixed binary layout. Port the same changes to the Unity client and re-generate the golden data file so both sides still agree tick-by-tick.

**Tech Stack:** Go 1.22 (server + sim + golden-export tool), C# / Unity 6 (client sim port), FNV-1a-64 canonical hash, Q16.16 fixed-point (`Fix32`).

**Determinism rule being preserved:** Rule 1 from Sub-1 — "No float in sim." Everything new uses `Fix32`/`Vec2`/integer counts only.

**Spec reference:** `docs/superpowers/specs/2026-04-19-sub2-gameplay-design.md` §3.1–§3.6, §9 Phase 0.

**DoD (must hold when all tasks are done):**
1. All Sub-1 Go tests (`go test ./internal/sim/... ./internal/sim/fixed/...`) pass.

### Fixed binary layouts (authoritative reference)

All integers are little-endian. All `Fix32` and `Vec2` components are the signed 32-bit raw Q16.16 value.

**Hash — per Unit (51 bytes, in this exact byte order):**
```
ID(4) | Owner(1) | State(1) | Type(1) |
HP(4) | Range(4) | Damage(4) | VisionRange(4) | CarryAmount(4) |
PosX(4) | PosY(4) | TargetID(4) |
AttackMoveTargetX(4) | AttackMoveTargetY(4) | PathLen(4)
```
If `PathLen > 0`, append each waypoint `X(4) | Y(4)` in array order after the 51-byte block.

**Hash — per Building (40 bytes + queue tail):**
```
ID(4) | Owner(1) | Type(1) | State(1) | SizeCells(1) |
PosX(4) | PosY(4) | HP(4) | MaxHP(4) |
ConstructProgress(4) | RallyPointX(4) | RallyPointY(4) | QueueLen(4)
```
Then for each `QueueItem`: `UnitType(1) | TicksLeft(4) | StartTick(4)` (9 bytes).

**Hash — per Crystal (16 bytes):**
```
ID(4) | PosX(4) | PosY(4) | Remaining(4)
```

**Hash — per Player (6 bytes):**
```
ID(1) | Crystal(4) | Surrendered(1)
```

**Hash — NavGrid (12 + 8·words bytes):**
```
W(4) | H(4) | BlockedWords(4) | Blocked[0..BlockedWords-1] each as u64 (8 bytes)
```

**Hash top-level mix order:**
```
Tick(4) | UnitCount(4) | Units[...sorted by ID, each 51+8·PathLen bytes] |
BuildingCount(4) | Buildings[...sorted by ID, each 40+9·QueueLen bytes] |
CrystalCount(4) | Crystals[...sorted by ID, each 16 bytes] |
PlayerCount(4) | Players[...sorted by ID, each 6 bytes] |
NavGrid(as above)
```

**Snapshot (Marshal) — header (56 bytes):**
```
Tick(4) | Seed(8) | RandState(8) | NextID(4) | MapSizeX(4) | MapSizeY(4) |
UnitCount(4) | BuildingCount(4) | CrystalCount(4) | PlayerCount(4) |
NavGridW(4) | NavGridH(4)
```
Then Units block, Buildings block, Crystals block, Players block, NavGrid Blocked words.

**Snapshot per-Unit (67 bytes + 8·PathLen):**
```
ID(4) | Owner(1) | State(1) | Type(1) |
HP(4) | MaxHP(4) | Speed(4) |
Range(4) | Damage(4) | VisionRange(4) | CarryAmount(4) |
PosX(4) | PosY(4) | TargetID(4) |
MoveToX(4) | MoveToY(4) |
AttackMoveTargetX(4) | AttackMoveTargetY(4) |
PathLen(4) | PathX0(4) | PathY0(4) ... PathX_{N-1}(4) PathY_{N-1}(4)
```
Total fixed = 1+1+1 = 3 byte-sized fields, then 16×4 = 64 u32 fields, = 67 before the path tail.

**Snapshot per-Building:** same 40 + 9·QueueLen layout as the hash, in the same byte order.

**Snapshot per-Crystal:** 16 bytes, same as hash.

**Snapshot per-Player:** 6 bytes, same as hash.

**Snapshot NavGrid block:** 4 (BlockedWords header u32) + 8·BlockedWords bytes. NavGrid W/H live in the header (not repeated here).

```go
package sim

// NavGrid is the A* collision bitmap. 1:1 with map cells (1 unit = 1 cell).
// Blocked[(y*W + x) / 64] bit (y*W + x) % 64 == 1 → cell is impassable.
// Buildings occupy their AABB cells; units do not enter the bitmap.
type NavGrid struct {
	W       int32
	H       int32
	Blocked []uint64
}

// NewNavGrid allocates a fresh all-passable grid sized (w, h).
func NewNavGrid(w, h int32) *NavGrid {
	total := int(w) * int(h)
	words := (total + 63) / 64
	return &NavGrid{
		W:       w,
		H:       h,
		Blocked: make([]uint64, words),
	}
}

// BlockedWords returns the length of the underlying word slice.
func (n *NavGrid) BlockedWords() int {
	return len(n.Blocked)
}
```

```csharp
                w.Units.Add(u);
            }

            for (int i = 0; i < bldCount; i++)
            {
                var b = new Building
                {
                    ID = br.ReadU32(),
                    Owner = br.ReadU8(),
                    Type = (BuildingType)br.ReadU8(),
                    State = (BuildingState)br.ReadU8(),
                    SizeCells = br.ReadU8(),
                    Pos = new Vec2(
                        Fixed32.FromRaw((int)br.ReadU32()),
                        Fixed32.FromRaw((int)br.ReadU32())),
                    HP = Fixed32.FromRaw((int)br.ReadU32()),
                    MaxHP = Fixed32.FromRaw((int)br.ReadU32()),
                    ConstructProgress = Fixed32.FromRaw((int)br.ReadU32()),
                    RallyPoint = new Vec2(
                        Fixed32.FromRaw((int)br.ReadU32()),
                        Fixed32.FromRaw((int)br.ReadU32())),
                };
                int qLen = (int)br.ReadU32();
                if (qLen > 0)
                {
                    b.ProductionQueue = new QueueItem[qLen];
                    for (int q = 0; q < qLen; q++)
                    {
                        b.ProductionQueue[q] = new QueueItem
                        {
                            UnitType = (UnitType)br.ReadU8(),
                            TicksLeft = br.ReadU32(),
                            StartTick = br.ReadU32(),
                        };
                    }
                }
                w.Buildings.Add(b);
            }

            for (int i = 0; i < crystCount; i++)
            {
                w.Crystals.Add(new Crystal
                {
                    ID = br.ReadU32(),
                    Pos = new Vec2(
                        Fixed32.FromRaw((int)br.ReadU32()),
                        Fixed32.FromRaw((int)br.ReadU32())),
                    Remaining = Fixed32.FromRaw((int)br.ReadU32()),
                });
            }

            for (int i = 0; i < playerCount; i++)
            {
                w.Players.Add(new Player
                {
                    ID = br.ReadU8(),
                    Crystal = Fixed32.FromRaw((int)br.ReadU32()),
                    Surrendered = br.ReadU8() != 0,
                });
            }

            int words = (int)br.ReadU32();
            var nav = new NavGrid { W = navW, H = navH, Blocked = new ulong[words] };
            for (int i = 0; i < words; i++)
                nav.Blocked[i] = br.ReadU64();
            w.NavGrid = nav;

            return w;
        }
    }
}
```

```go
import (

// goldenDataPath resolves the Unity-side GoldenData.json via a relative path,
// so both Go and Unity tests read the same file.
func goldenDataPath(t *testing.T) string {
	t.Helper()
	// This test file lives in internal/sim/; the JSON lives at
	// ../../../_Unity/rts-client-unity/Assets/Tests/EditMode/GoldenData.json
	candidates := []string{
		filepath.Join("..", "..", "..", "_Unity", "rts-client-unity",
			"Assets", "Tests", "EditMode", "GoldenData.json"),
	}
	for _, p := range candidates {
		if _, err := os.Stat(p); err == nil {
			return p
		}
	}
	t.Skipf("GoldenData.json not found (searched %v) — run cmd/golden-export first", candidates)
	return ""
}

func TestPhase0_EmptyWorldHash_MatchesGolden(t *testing.T) {
	path := goldenDataPath(t)
	data, err := os.ReadFile(path)
	if err != nil {
		t.Fatalf("read golden: %v", err)
	}
	var g struct {
		EmptyWorldHash string `json:"emptyWorldHash"`
	}
	if err := json.Unmarshal(data, &g); err != nil {
		t.Fatalf("parse golden: %v", err)
	}
	if g.EmptyWorldHash == "" {
		t.Fatal("emptyWorldHash missing from GoldenData.json — re-run cmd/golden-export")
	}
	want := g.EmptyWorldHash

	w := NewWorld(42, 100, 100)
	got := fmt.Sprintf("%016x", Hash(w))

	if got != want {
		t.Fatalf("empty-world hash mismatch: got %s, want %s", got, want)
	}
}
```

## Deviation notes from spec §3.2

The spec uses `St*` state name prefixes (`StIdle`, `StMoving`, …) and `Bld*` building-state prefixes. This plan retains the `Unit*` / `Bld*` prefix style already used in Sub-1 Go code so existing callers (`room.go`, `step.go`, tests) do not churn — only the numeric values change. C# uses enum member names without prefix (`UnitState.Idle`, `BuildingState.Constructing`), matching the idiomatic C# style already established in Sub-1.

`UnitDead` is re-numbered from `2` → `6`; this is an intentional, spec-driven breaking change — it is why we regenerate `GoldenData.json` in Task 11.
